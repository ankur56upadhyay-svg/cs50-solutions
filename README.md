# 🎓 CS50 Problem Solutions

This repository contains my standard C implementations of the problem sets from Harvard University's CS50x course. 

## 🚀 Problem 1: Mario (Week 1)
**File:** `mario.c`

**Description:** 
A C program that recreates the double half-pyramid seen at the end of Super Mario Bros. using hashes (`#`). It prompts the user for a pyramid height and dynamically generates the structure using nested loops.

**Developer Note:** 
As a beginner, wrapping my head around the logic for the nested loops to handle the exact spacing and hashes took me about 3 to 4 hours. It was a major struggle initially, but after removing the CS50 training wheels and writing it in standard C, the core logic finally clicked. What felt impossible yesterday feels easy today.

## 🛠️ Tech Stack
* **Language:** C
* **Compiler:** GCC (Local Windows Environment)
